Review AI pipeline changes before they become recurring costs.

TokenDiff checks each pull request for new prompt growth, redundant tool calls, and unnecessary agent handoffs. It posts evidence-backed, advisory suggestions directly on the PR.

01

The change under review

Review changes that increase the context sent between steps.

TokenDiff focuses on the delta. It looks for the moment a PR starts replaying growing transcripts, duplicating retrieval, or making specialist work unconditional.

03

One bounded review

The review is opinionated about evidence, not architecture.

  1. 1Read the PR diff

    Compare immutable merge-base and head revisions. Changed code stays first in the context budget.

  2. 2Retrieve relevant guidance

    Ground suggestions in a local catalog of routing, compression, and agent-design techniques.

  3. 3Validate the response

    Reject unsupported locations, invented evidence, and citations that were not retrieved.

Get started

One workflow. Your provider key.

Use Gemini or OpenAI. TokenDiff has no account, hosted backend, or telemetry. Reviews are advisory and never fail the workflow because they found something.

.github/workflows/tokendiff.yml
name: TokenDiff
on: pull_request

permissions:
  contents: read
  pull-requests: write

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: umer901/TokenDiff@v0.1.0
        with:
          provider: gemini
          model: ${{ vars.TOKENDIFF_GEMINI_MODEL }}
          api-key: ${{ secrets.GEMINI_API_KEY }}
